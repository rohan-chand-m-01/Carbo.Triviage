## Vision: The 1.5 Degree Operating System

CarbonLens is a Hyper-Intelligence Engine built for the future of the global economy. As regulations like CBAM and CSRD move from voluntary to mandatory, CarbonLens provides the immutable audit trail and real-time optimization needed to lead in a net-zero world.

## Premium Systems

### Architecture and Design
*   **Midnight-Dark Core:** A sleek, high-contrast aesthetic designed for mission-critical command centers.
*   **Glassmorphic Interface:** Frosted-glass components with subtle mesh gradients for a futuristic feel.
*   **Parallax Intelligence:** Immersive scroll-triggered animations powered by Framer Motion.

### AI Native Engine
*   **Autonomous Anomaly Detection:** Instantly flags variations in supply-chain emission intensity.
*   **Strategy Simulation:** Forecast the carbon and cost delta of logistics shifts in seconds.
*   **Automated Regulatory Drafting:** Generates CSRD-compliant reports and CBAM declarations using production-grade AI models.

### Global Grid Connectivity
*   **Live Data Integration:** Direct connection with Electricity Maps, Ember, and the World Bank.
*   **Sub-second Precision:** Monitor facility-level grid intensity as it happens.
*   **Immutable Audit Trail:** Built-in verification for every emission record, ensuring audit-readiness.

## Installation and Setup

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/rohan-chand-m-01/Carbo.Triviage
    cd Carbo.Triviage
    ```

2.  **Install Dependencies**
    ```bash
    npm install --legacy-peer-deps
    ```

3.  **Environment Setup**
    Configure the `.env.local` file using the provided template. Sensitive keys are secured and excluded from version control.

4.  **Database Migration**
    ```bash
    npx prisma db push
    ```

5.  **Start Development Server**
    ```bash
    npm run dev
    ```
