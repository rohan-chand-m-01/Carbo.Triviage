## 🚀 Vision: The 1.5°C Operating System

CarbonLens is not just an accounting tool; it's a **Hyper-Intelligence Engine** built for the future of the global economy. As regulations like CBAM and CSRD move from voluntary to mandatory, CarbonLens provides the immutable audit trail and real-time optimization needed to lead in a net-zero world.

## ✨ Premium Features

### 💎 Elite UI/UX Index
*   **Midnight-Dark Core:** A sleek, high-contrast aesthetic designed for mission-critical command centers.
*   **Glassmorphic Interface:** Frosted-glass components with subtle mesh gradients for a futuristic feel.
*   **Parallax Intelligence:** Immersive scroll-triggered animations powered by `framer-motion`.

### 🧠 AI Native Engine (Gemini Ultra)
*   **Autonomous Anomaly Detection:** Instantly flags variations in supply-chain emission intensity.
*   **Strategy Simulation:** Forecast the carbon/cost delta of logistics shifts (e.g., Rail vs. Sea) in seconds.
*   **Automated Regulatory Drafting:** Generates CSRD-compliant reports and CBAM declarations using production-grade LLMs.

### 🌐 Global Grid Connectivity
*   **8+ Live Data Sources:** Direct integration with Electricity Maps, Ember, and the World Bank.
*   **Sub-second Precision:** Monitor facility-level grid intensity as it happens.
*   **Immutable Audit Trail:** Built-in verification for every emission record, ensuring audit-readiness.

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router + Turbopack)
- **Styling:** Tailwind CSS (Custom Mesh Tokens)
- **Database:** PostgreSQL (Supabase) + pgvector
- **ORM:** Prisma
- **Auth:** Clerk (Enterprise Tier)
- **Animations:** Framer Motion
- **Services:** Inngest (Background Jobs), Upstash (Redis Caching)

## 📦 Getting Started

1.  **Clone the Repo:**
    ```bash
    git clone https://github.com/rohan-chand-m-01/Carbo.Triviage
    cd Carbo.Triviage
    ```

2.  **Install Dependencies:**
    ```bash
    npm install --legacy-peer-deps
    ```

3.  **Environment Setup:**
    Create a `.env.local` based on the provided template (Keys are secured and not committed).

4.  **Database Sync:**
    ```bash
    npx prisma db push
    ```

5.  **Launch Command Center:**
    ```bash
    npm run dev
    ```
